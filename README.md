# Akanome Agency

A dynamic team showcase page built with **Next.js**, **GSAP**, and **Tailwind CSS**.

## Features

- Gaussian blur hero reveal animation with white-to-dark scroll transition
- Custom `RevealLoader` with logo fade-in/out and animated bar exit
- Holographic tilt profile cards (React Bits `ProfileCard`)
- Animated `StarBorder` component around each card
- GSAP `ScrollTrigger` for title and card entrance animations
- Lenis smooth scroll integration

## Tech Stack

- [Next.js](https://nextjs.org/) — App Router, TypeScript
- [Tailwind CSS v4](https://tailwindcss.com/)
- [GSAP 3](https://gsap.com/) + ScrollTrigger + `@gsap/react`
- [Lenis](https://lenis.studiofreight.com/) — smooth scroll

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
